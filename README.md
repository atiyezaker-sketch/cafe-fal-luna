# کافه فال لونا — نسخه اولیه

این برنامه یک نمونهٔ اولیهٔ Node.js است که صفحهٔ اصلی فارسی، انتخاب نوع فال، فرم نیت و صفحهٔ نتیجهٔ آزمایشی دارد.

## اجرا
- Node.js نسخهٔ 18 یا بالاتر لازم است.
- دستور `npm start` را اجرا کنید.
- در Render نوع سرویس Web Service، محیط Node را انتخاب کنید و دستور Build را خالی/`npm install` و Start را `npm start` بگذارید.

## مهم
- این نسخه هنوز به API میکسین، ترب‌پی/زرین‌پال یا سرویس هوش مصنوعی متصل نیست.
- نتیجه‌ها آزمایشی‌اند و داخل حافظهٔ موقت نگهداری می‌شوند؛ پس از راه‌اندازی مجدد سرور پاک می‌شوند.
- برای اتصال واقعی پرداخت باید مستندات دقیق API، روش احراز هویت و وضعیت سفارش موفق بررسی شود. کلیدها و توکن‌ها را در متغیرهای محیطی Render ذخیره کنید و هرگز در چت یا کد عمومی قرار ندهید.
